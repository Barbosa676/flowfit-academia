# FlowFit

Sistema de gestão de clientes para academias, construído com Python + Tkinter + SQLite.

FlowFit é uma aplicação desktop para controlar o cadastro de alunos, organizar dados pessoais e manter uma interface limpa, moderna e fácil de usar.

## ✨ Funcionalidades

- Cadastro de clientes
- Edição de dados cadastrais
- Exclusão de clientes
- Listagem em tabela
- Persistência local com SQLite
- Interface premium para academias
- Visual moderno e responsivo para desktop

## 🏋️ Tech Stack

- Python 3
- Tkinter
- SQLite

## 🚀 Como executar

1. Certifique-se de ter o Python 3 instalado.
2. Acesse a pasta do projeto:

```bash
cd /home/gabriel/Documentos/maps
```

3. Execute a aplicação:

```bash
python3 gym_main.py
```

## 🧪 Requisitos

O projeto usa apenas a biblioteca padrão do Python e o Tkinter, então normalmente basta ter o Python 3 instalado no sistema.

## 📦 Banco de dados

Os dados são armazenados localmente em SQLite, no arquivo dentro do pacote da aplicação.

## 🧑‍💻 Uso

- Preencha os campos de nome, email e telefone
- Clique em “Adicionar cliente”
- Selecione um cliente na tabela para editar ou excluir

## 📝 Observações

Este projeto foi pensado como uma solução simples, leve e funcional para gestão básica de clientes em academias.
